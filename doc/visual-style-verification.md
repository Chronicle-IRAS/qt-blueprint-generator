# 界面样式验收指南

本指南用于检查 Qt Widgets 编辑器的主题一致性、中英文布局和 Windows 缩放。视觉验收只需虚构蓝图和离线候选，不需要 API 密钥，不应点击真实连接测试或生成请求。

## 检查环境

- 构建当前分支，确保 Qt DLL 可由进程 PATH 找到。
- 分别检查英文、简体中文。语言菜单切换后，已打开的对话框和输入内容应保持正常。
- 常用桌面窗口：1280×800；较小窗口：1024×700。保持属性与构建面板可见，再测试停靠、浮动、隐藏和恢复布局。
- Windows 显示缩放检查 100%、125%、150%、200%。实际可用逻辑尺寸取决于显示器分辨率；必要时最大化或调整 Dock，不应通过缩小字体来掩盖布局问题。
- 自动化可在独立进程设置 `QT_SCALE_FACTOR` 模拟比例；它不能完全代替实际显示器、系统字体和多屏移动检查。

## 主窗口与面板

1. 菜单、工具栏、面板标题、按钮、输入框应使用一致的浅色主题、深色文字和蓝色强调色。
2. 用鼠标悬停、按下按钮，再用 Tab 移动焦点；状态清晰，控件不应跳动。禁用操作不能被触发，文字仍可辨认。
3. 缩小窗口，确认工具栏的溢出入口仍能访问隐藏操作；不要要求所有长文字按钮在一行完整展示。
4. 在属性面板输入长中英文节点名称、端口类型和说明。表格可调整/滚动，不能无限撑宽整个窗口；行内删除按钮不应被切掉。
5. 缩小底部构建面板，滚动表单访问全部输入项；日志区域仍能查看。构建、导出入口行为与旧版一致。
6. 从 View 菜单隐藏并重新显示面板，再执行 Reset Layout；恢复正确停靠位置与可见性。

## 画布

1. 创建不同节点类型，检查标题、正文、端口和连线的层次。长标题省略时，应有查看完整内容的途径。
2. 节点悬停、选中、兼容输入端口高亮应可区分，且不改变端口位置或拖拽命中区域。
3. 拖动节点、连接端口、删除并撤销，确认箭头端点仍贴合端口，Decision 标签未被裁切。
4. 缩放与平移画布，网格保持轻量，不遮挡文字，也不在缩小时变成高密度噪声。

## 对话框

1. AI 设置：字段标签可读，端点和模型输入可伸展，提示文字可换行；取消不会保存改动。
2. 候选审核：文件列表、当前文件与候选代码层次清晰，代码使用等宽字体；差异高亮不应覆盖或降低文字可读性。
3. 在中英文下检查接受、接受编辑、拒绝、刷新和取消操作的文字及按钮边界；两个代码栏均可访问。
4. 切换语言、编辑草稿、调整窗口大小后，审核状态和草稿不能丢失。
5. 按 Tab 和 Escape 检查键盘焦点和关闭行为；主题不能改变原有确认、冲突处理与审核安全边界。
